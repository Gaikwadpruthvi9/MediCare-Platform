# MediCare Platform

MediCare is a comprehensive healthcare platform featuring a patient-facing frontend, administrative dashboard, and backend services.

## Project Structure

```text
├── admin/       # Admin dashboard for managing doctors, services, and appointments
├── backend/     # Backend models, controllers, and APIs
└── frontend/    # Patient portal and main web application
```

## Features

- **Doctor Appointment Booking**: Schedule appointments with healthcare specialists.
- **Service Booking**: Book medical services, checkups, and diagnostic tests.
- **Admin Management**: Dedicated portal to manage doctors, services, and appointment schedules.
- **Doctor Portal**: Doctor dashboard to view appointments and manage availability.
